### Question/Réponse 7 ###
Q1: What is the focus of this document?
R1: The focus of this document is to provide a specification for Windows Registry Forensic Tools that can handle hive files, hive sets, and disk image files containing at least one Windows system partition.

Q2: What is the purpose of a registry hive file in this context?
R2: A registry hive file is an offline registry file that physically stores registry objects including keys, values, and data. A primary hive file may exist along with multiple transaction log files.

Q3: What is a hive set in the context of this document?
R3: A hive set consists of primary hives and their transaction log files, which include SAM, SYSTEM, SOFTWARE, SECURITY, and pairs of [NTUSER, USRCLASS] for each Windows account. Multiple hive sets can be found from Restore Points (Windows XP and earlier) as well as Volume Shadow Copies (Windows Vista and later) stored within a Windows system partition if relevant features are turned on.
